# 👔 Employee Management System (WPF)

A desktop application built with **WPF (Windows Presentation Foundation)** in **C#**, designed to help businesses manage employees, roles, and departments efficiently.

---

## 📌 Features

- 🧑 Add, edit, delete employees
- 🏢 Manage departments and roles
- 🔎 Search and filter employees
- 💾 Save data to a local database (e.g. SQL Server)
- 🧭 Clean and user-friendly WPF interface (MVVM Pattern)

---

## 🖥️ Technologies Used

- .NET (C#)
- WPF (XAML)
- MVVM Architecture
- SQL Server / SQLite *(tùy bạn chọn)*
- Entity Framework Core (ORM)
